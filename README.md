# Arkansas Valley Senior Resources App

A simplified, high-contrast, easy-to-use web application designed to help seniors in the Arkansas River Valley connect with essential services.

## Features
- **Wizard Interface**: Simple "What do you need?" question to start.
- **High Accessibility**: Large text, clear buttons, high contrast.
- **Local Focus**: Specifically targeted at rural Colorado resources.
- **Mobile First**: Optimized for phones and tablets.

## Tech Stack
- React + Vite
- Tailwind CSS v4 (Sage & Sandstone Palette)
- Lucide React (Icons)

## Setup & Run Locally

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```

3.  **Build for Production**:
    ```bash
    npm run build
    ```

## Deployment
This app is ready for deployment.
- **GitHub Pages**: You can use the `gh-pages` package or a GitHub Action to deploy the `dist` folder.
- **Vercel/Netlify**: Simply connect the repository and it will auto-detect Vite.
